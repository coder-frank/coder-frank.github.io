What I worked on

  • Worked on the Laravel backend's production environment and deployment workflow.
  • Configured GitHub Actions-based deployment using SSH and Composer.
  • Resolved static asset loading, PHP handler and application route issues.
  • Supported authentication, public path and routing investigation.

Technical considerations

  • Keep distinct permissions for buyers, agents and administrators.
  • Serve Laravel's public directory with correct rewrite rules.
  • Use reproducible deployment commands, migrations and cache rebuilding.
  • Protect private documents and transaction-related data with authorization.
