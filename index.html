04 / ABOUT ME

A little about how I work.

I’m Ebuka Francis Mbanusi. Most of my time goes into Laravel backends: figuring out how data moves, getting payment callbacks right, making slow tasks asynchronous, and keeping applications dependable after deployment.

I work across the stack when needed — React on the web, React Native on mobile, and Linux servers when software needs to reach production. I care about straightforward code and solving the actual problem.

Core Focus

  • API design & docs (OpenAPI / Swagger)

  • Queues, jobs, schedulers, notifications (Mail/FCM)
  • Mobile apps (React Native + Expo)
  • AI & automation workflows (Python + MT5)
